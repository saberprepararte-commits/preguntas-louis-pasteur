# Página web: Ejercicios aleatorios Louis Pasteur

Esta carpeta está lista para publicarse como una página web estática.

## Archivo principal

- `index.html`: aplicación completa en HTML, CSS y JavaScript.

## Cómo subirla a GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube el archivo `index.html` a la raíz del repositorio.
3. Entra a **Settings** > **Pages**.
4. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Guarda los cambios.
6. Espera unos minutos y GitHub generará el enlace público de la página.

## Nota

No necesitas instalar nada. La página funciona directamente en el navegador porque todo está dentro de `index.html`.
